# Task Tracker Demo — Backend

This repository contains the backend part of a fullstack demo project built with **Java**, **Spring Boot**, and **PostgreSQL**.  
You can find the frontend here:  
👉 [Task-Tracker-demo-FE](https://github.com/Petr0611/Task-Tracker-demo-FE/tree/TT_demo)

🔧 Tech Stack  
- Java 17 + Spring Boot  
- PostgreSQL  
- Docker  
- GitHub Actions (CI/CD)  
- REST API with role-based access  

✨ Features  
- Secure ownership transfer and access control  
- Robust error handling and DTO mapping  
- Integration-ready REST API for frontend consumption  
- CI/CD pipeline for automated builds and tests  

📁 Structure  
- `src/main/java` → Controllers, Services, DTOs, Config  
- `src/test/java` → Unit and integration tests  
- `.github/workflows/` → CI/CD configuration  

🎯 Purpose  
This demo repository was created to showcase backend architecture, API design, and production-ready Spring Boot setup.  
It is intended for clients and recruiters to evaluate backend development and DevOps skills.
